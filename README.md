# 🎓 Grades Calculator

A simple Python program that reads a list of grades, validates them, and calculates the average and the final degree.

## ✨ Features

- Reads the number of grades and each grade, and stores them in a list.
- Input validation (rejects negative values and zero).
- Average calculation.
- Final degree: Excellent, Very Good, Good, Pass, or Fail.

## 🛠️ Built With

- Python
- Lists
- While and For Loops
- Conditional Statements

## ▶️ How to Run

Run "grades.py" using Python.

Created as a Python practice project.
